# Fonts

The template is strict about using an approved font.

For Times New Roman, you may privately place these files here:

- `times.ttf`
- `timesbd.ttf`
- `timesi.ttf`
- `timesbi.ttf`

These files are not included because Microsoft fonts generally cannot be redistributed
in a public GitHub repository.

If your system has Times New Roman installed and XeLaTeX/LuaLaTeX can find it, this
folder can stay empty.
